# نرم‌افزار حسابداری فروشگاه FMCG

سیستم مدیریت فروشگاه مبتنی بر Odoo 18 Community Edition با شخصی‌سازی‌های اختصاصی.

## ✨ قابلیت‌ها

- 🏦 **مدیریت بانک و صندوق** — تعریف حساب بانکی و صندوق، مانده‌ جاری
- 📦 **انبارداری** — محصولات FMCG، هشدار موجودی کم، تعدیل موجودی
- 💰 **حسابداری ساده** — ثبت هزینه، سند حسابداری دوطرفه اتوماتیک
- 📊 **گزارش‌ها** — فروش روزانه، وضعیت انبار، سن بدهی مشتریان، جریان نقدی
- 💳 **اتصال دستگاه پوز** — ارسال اتوماتیک مبلغ به دستگاه کارتخوان
- 🤝 **پرداخت اعتباری** — ثبت بدهی مشتری با یادداشت، بازپرداخت
- 🇮🇷 **فارسی‌سازی** — رابط کاربری فارسی، RTL، تقویم شمسی
- 📴 **حالت آفلاین** — ادامه کار بدون اینترنت، سینک اتوماتیک

## 🚀 نصب و راه‌اندازی

### پیش‌نیازها

- Python 3.10+
- PostgreSQL 14+
- Git

### مراحل نصب

```powershell
# 1. کلون پروژه
git clone https://github.com/pouyamotamedi/odoo-fmcg-accounting.git
cd odoo-fmcg-accounting

# 2. کلون Odoo 18
git clone --depth 1 --branch 18.0 https://github.com/odoo/odoo.git odoo

# 3. ساخت محیط مجازی
python -m venv venv
.\venv\Scripts\activate
pip install -r odoo/requirements.txt
pip install jdatetime pyserial

# 4. ساخت دیتابیس (بدون داده نمونه)
# (اول PostgreSQL رو نصب و اجرا کنید)
psql -U postgres -c "CREATE USER odoo WITH CREATEDB PASSWORD 'odoo';"
psql -U postgres -c "CREATE DATABASE fmcg_shop OWNER odoo;"

# 5. نصب ماژول‌ها
python odoo/odoo-bin -c odoo.conf --stop-after-init --without-demo=all -i base,fmcg_base,fmcg_bank_cash,fmcg_inventory,fmcg_accounting,fmcg_credit,fmcg_pos_terminal,fmcg_persian,fmcg_reports,fmcg_offline --load-language=fa_IR

# 6. اجرای سرور
python odoo/odoo-bin -c odoo.conf
```

سپس مرورگر را باز کنید: **http://localhost:8069**

### اطلاعات ورود اولیه
- **ایمیل:** admin
- **رمز:** admin

## 📖 راهنمای استفاده

### تنظیمات اولیه (فقط یک بار)

1. **زبان فارسی:** Settings > Users > Admin > Preferences > Language = فارسی
2. **واحد پول:** Settings > Companies > شرکت > Currency = IRT (تومان)
3. **تنظیمات فروشگاه:** Settings > FMCG Shop > تنظیمات دلخواه

### کجا چیه؟

| کار | مسیر |
|-----|------|
| فروش صندوقی (POS) | صندوق فروش > جلسه جدید |
| فاکتور فروش | صورتحساب > فاکتورها > جدید |
| فاکتور خرید | صورتحساب > صورتحساب فروشنده > جدید |
| ورود کالا به انبار | انبار > عملیات > رسیدها |
| خروج کالا | انبار > عملیات > تحویل‌ها |
| ثبت هزینه | مالی > هزینه‌ها > جدید |
| اعتبار مشتری | مالی > اعتبار مشتریان > جدید |
| حساب‌های بانکی | مالی > بانک و صندوق > حساب‌های بانکی |
| صندوق‌ها | مالی > بانک و صندوق > صندوق‌ها |
| تعدیل موجودی | انبار > انبار FMCG > تعدیل موجودی |
| تنظیم کارتخوان | صندوق فروش > تنظیمات > دستگاه‌های پوز |
| گزارش فروش روزانه | مالی > گزارش‌ها > خلاصه فروش روزانه |
| گزارش موجودی | مالی > گزارش‌ها > وضعیت موجودی |
| گزارش بدهی مشتریان | مالی > گزارش‌ها > سن بدهی مشتریان |
| گزارش جریان نقدی | مالی > گزارش‌ها > جریان نقدی |
| لاگ سینک | مالی > لاگ سینک |

### گردش کار فروش

1. **ثبت محصول:** انبار > محصولات > جدید > نام، بارکد، قیمت خرید، قیمت فروش
2. **ورود کالا:** انبار > عملیات > رسیدها > محصول و تعداد رو وارد کنید
3. **فروش POS:** صندوق فروش > جلسه جدید > محصولات رو انتخاب > پرداخت
4. **پرداخت نقدی:** مبلغ دریافتی رو وارد > باقی‌مانده محاسبه میشه
5. **پرداخت کارتی:** مبلغ اتوماتیک به دستگاه ارسال میشه (اگه متصل باشه)
6. **پرداخت اعتباری:** مشتری رو انتخاب > مبلغ ثبت میشه روی حسابش

### اتصال دستگاه کارتخوان

1. صندوق فروش > تنظیمات > دستگاه‌های پوز > جدید
2. نام: نام دستگاه، پروتکل: Serial، پورت: COM3 (شماره واقعی)
3. تست اتصال بزنید
4. اگه دستگاه متصل نباشه میتونید شماره مرجع رو دستی وارد کنید
